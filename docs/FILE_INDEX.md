# File index

## Application
- lib/main.dart: application bootstrap, theme and three-tab shell.
- lib/screens/: catalog, plan editor, workout detail, history and settings.
- lib/models/workout.dart: both entity types and validation.
- lib/data/: SQLite repository and preference adapter.
- lib/services/plan_helper.dart: deterministic local ranking and baseline.
- lib/state/quest_controller.dart: shared saved data and operation state.
- lib/widgets/common.dart: reusable plan cards, notices and dialogs.

## Verification and setup
- test/: 14 repository, 10 helper and 2 widget cases.
- integration_test/: native database/preference persistence case.
- tool/: reproducible helper fixtures/evaluator and host SQL schema audit.
- scripts/: Android scaffold, automated verification and release build scripts.
- evidence/: actual helper/schema outputs, syntax check and supplied Oct 18 screenshot.

## Documents
- START_HERE.md and README.md: first steps and setup.
- ARCHITECTURE.md, AI_FEATURE.md, AI_Usage_Log.md, CONTRIBUTIONS.md.
- docs/design/: five wireframe sheets (five states each), three storyboards, annotations, map and data sketch.
- docs/RUBRIC_AUDIT.md: actual undergraduate criteria, not the earlier crosswalk.
- docs/DEMO_SCRIPT.md: timed 23-minute explanation guide.
- docs/testing/: manual procedures, unfilled actual-result matrix and honest test status.
- docs/FINAL_SUBMISSION_CHECKLIST.md and docs/OCT24_CHECKPOINT.md.
- submission/: report PDF, selected questions Word file, PowerPoint, setup PDF, submitted proposal copy and documentation copies.
- Kanban_Contribution_Evidence.pdf: partial workbook requiring real missing evidence before final submission.

The submission folder intentionally lacks a claimed approved proposal, signed acknowledgment, release APK and real video link until those are provided or verified.
