# User guide

1. Catalog: select Create plan. Give the plan a name, choose an exercise/equipment, set targets and a personal intensity label, then Save.
2. Open the plan. Start creates or resumes a saved draft. Enter actual repetitions and select Log set for each planned set. The saved-set count changes after the write succeeds.
3. Use Edit set to correct a saved value. Undo last set removes the most recent saved set. Finish is enabled when every planned set has been recorded.
4. Back offers Keep draft and leave, Discard draft or Stay. A kept draft resumes next time. Reset deletes only the current draft after confirmation.
5. History lists completed sessions. Add past session requires an existing plan, a valid nonfuture YYYY-MM-DD date and exactly the planned number of comma-separated repetition values. Edit corrects a log; Delete removes it after confirmation.
6. Catalog equipment filter changes the displayed plans and their completed-session total. The helper ranks all saved plans independently of this display filter.
7. Settings controls theme, equipment preference and reduced motion. Save failures retain the last saved preference and provide Retry.
8. Helper Apply opens a plan without starting a session. Not now dismisses the suggestion. You may choose any plan.
9. Delete plan warns that all associated drafts and completed history will be removed. Cancel preserves everything.

If a save fails, keep your values and retry the same action. If records cannot be read, use Retry. The app does not require networking for its core functions.
