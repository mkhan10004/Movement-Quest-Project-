# Known limitations and remaining checks

- Native Android scaffold is generated by scripts/prepare_android.ps1 using the team's installed SDK. Android project, Gradle dependencies and APK are not built in this handoff.
- Package ranges have not been resolved here. Commit the resulting pubspec.lock and record SDK version after successful local setup. Flutter >=3.35 and Dart >=3.9 are needed.
- Full Flutter analyzer, unit/widget/integration runs, actual two-device layouts, force-stop/restart and release-install checks are pending.
- Helper evaluation uses 7 valid synthetic preference labels and 3 empty/invalid checks. It is not held-out or user-study evidence.
- Manual session entry uses local calendar dates and stores midnight. Date corrections intentionally replace the session time; exact time editing is not part of this scope.
- Parent deletion permanently removes its logs after confirmation; there is no soft delete or backup.
- Data is local only. There is no account, remote sync, cloud AI, export/import or wearable integration.
- Complete history loads into memory for this small course dataset. Pagination would be a future improvement, not a measured optimization claim.
- The initial screen designs are included. A real peer-tested revision and verification still need documentation.
- Official signed acknowledgment, approval evidence, video, missing board snapshots and actual contribution traces must be supplied by the team.
